## 可复现抽样

视频种子为 20261015。先保留全部 178 个评测源视频，再按字幕关键词主题 × 字幕长度四分位进行比例分层抽取候选视频，目标 1,725 个（约 20%）。失效候选在同一分层中按固定顺序补选；失效的评测源视频单独报告。未使用答案内容、模型输出或实验分数选择样本。

视频采用最高 480p，保存音轨和官方套件提供的字幕。该候选库是缩减设置，会改变检索难度；实验应明确报告子集设置，不与完整候选库结果直接等同。

详细 ID、抽样规则、源地址和输入哈希：manifests/videorag_plan.json。成功文件哈希和媒体校验：manifests/video_records/。失败视频：manifests/videorag_results.json。图片逐文件 SHA-256 和可读性：manifests/okvqa_images.json。总体机器可读汇总：manifests/SUMMARY.json。

## 使用

运行前设置 OMNIAWARE_ASSETS 为 assets 的绝对路径，OMNIAWARE_CACHE 为 cache，OMNIAWARE_UNIVERSALRAG_DIR 为 omniaware/external/UniversalRAG。Linux 迁移时保留目录结构；OK-VQA 输入图片路径已写为相对资产根目录的路径。

GS-112K 是默认训练来源语料；GS-168K 包含评测题检索内容，仅供项目规定的附录对照。

下一步仍需安装实验环境和模型，并执行 BGE／CLIP／UniversalRAG 特征编码、共享候选池导出及视频抽帧；本次没有执行模型实验。

原始视频评测问题文件保持完整。只有证据可用的问题写入 dataset/query/videorag_synth_available.json；若覆盖率低于 100%，必须显式采用可用问题子集或补齐缺失视频后再运行，不能静默跳题。
