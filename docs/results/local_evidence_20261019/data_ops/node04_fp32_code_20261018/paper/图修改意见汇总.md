# 图修改意见汇总（对应 V3.15）

本文汇总了这一路以来所有涉及图的意见，来源包括：EMNLP 审稿意见（sjbm、yzib）、`WWW投稿_审稿意见对照与修改清单.md`（P0-6 等）、《科研全流程与论文写作指南》第 4.3、10.3、12.2、13.3 节、GPT 评审（F1、S8 和 4.1 节），以及我对 fig1–fig3 源文件的检查（矢量坐标复算、字体与字号提取、放大逐项核对）。

每条都标了来源和优先级：**P0** 不改会被审稿人直接质疑；**P1** 明显影响观感或准确性；**P2** 建议改。
