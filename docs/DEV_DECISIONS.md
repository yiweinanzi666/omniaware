## 规则

1. **EAB 形式只选一种，全局通用。** 指标是同一输入下 EAB 相对 static 的逐题增益：先在每个数据集内取平均，再对数据集取平均（每个数据集权重相同）。选平均增益最大的形式。"EAB 有效"当且仅当经过 **6 选 1 的 max-statistic bootstrap 校正**（D8）后，所选形式增益的 95% 区间下界大于 0；零假设分布取每次 bootstrap 重采样中 6 个候选增益的最大值。不允许按数据集分别选择。
2. **不确定性设置。** 指标是门控分数与直答错误的 Spearman ρ，跨数据集取平均；选 ρ 最大的设置。"U 优于 NTE"当且仅当所选设置的平均 ρ 大于下一 token 熵的平均 ρ。
3. **OK-VQA 语料。** 选 static − direct 差值最大的语料。"检索有用"当且仅当这个差值 ≥ 0；否则 OK-VQA 在论文中作为"检索可能有害、门控用来避免伤害"的场景报告，不作为增益来源。
4. **数值选择（D7，新增）。** 起点为论文值 (γ, β, τ_b, τ) = (1.2, 0.3, 0.4, 0.35)，按 **γ → (β, τ_b) → τ** 的顺序做坐标搜索。每一步选使"数据集等权平均的 dev 分数"最大的取值（门控 EAB 臂；WebQA 为 acc_approx，OK-VQA 为 VQA 准确率，HybridQA 为 EM，VideoRAG-Synth 为 ROUGE-L）；平局取较小的值。δ = 0.08 固定。在 test 上做的 β × τ_b 与 τ 扫描**只作为敏感性报告**，不参与任何选择。
5. **其余超参数不再调整。** k = 5 保持论文值。
6. **最佳候选的乐观偏差。** dev 上的选择存在 best-of-K 偏差（EAB 有 6 个候选，数值网格另有 15 + 5 + 3 个候选），所以论文中的所有数字只来自 test，dev 数字不进正文。
7. **执行规则（S-7）。** dev 结果缺失、题数不足、或分数含 NaN 时，`dev_select` 报错退出，不写出 `dev_decisions.json`。test 阶段要求 `dev_decisions.json` 存在且模型名与所跑模型一致；否则报错，不回退到默认值。
